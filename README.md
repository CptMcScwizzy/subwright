# subwright

Watches a folder and generates English subtitles for video, using
[faster-whisper](https://github.com/SYSTRAN/faster-whisper) on an NVIDIA GPU.
Drop a file in, get a `.srt` beside it. There is a small web UI for monitoring
and configuration.

It uses Whisper's *translate* task, so the output is English regardless of the
source language.

## What it does

Point it at a folder. It creates two directories inside:

```
<watch folder>/
├── ingest/       drop a video here
├── reprocess/    drop a video here to regenerate its subtitles in place
└── <video name>/ created for you
    ├── <video name>.mkv
    ├── <video name>.srt
    └── .translated
```

- **ingest/** — the video is moved into its own folder, then transcribed.
- **reprocess/** — the video stays put; its `.srt` is regenerated, with the
  previous one kept as a timestamped `.bak`.

A file is ignored until it has been untouched for 10 seconds, so a copy still in
progress is never picked up half-written.

### More than one folder

The **Folders** page turns that single layout into a list. Each row has its own
drop folder, output folder and source language, so a folder you know is Japanese
and one you know is Korean can each be pinned rather than guessed at:

| Name | Drop folder | Output | Language |
|---|---|---|---|
| anime | `/media/jp/ingest` | `/media/jp` | Japanese |
| kdrama | `/media/kr/ingest` | `/media/kr` | Korean |
| unsorted | `/media/in` | `/media/sorted` | auto-detect |

A folder can be switched off without being removed, and removing a row stops it
being watched without deleting anything on disk. With no folders configured you
get exactly the single-folder layout above, so nothing changes on upgrade.

## Running it

```yaml
services:
  subwright:
    image: ghcr.io/cptmcscwizzy/subwright:v0.1.0
    user: "1000:1000"
    ports: ["8420:8420"]
    environment:
      - SW_WATCH_DIR=/media/translate
      - SW_LANGUAGE=ja          # blank to auto-detect
    volumes:
      - /media/translate:/media/translate
      - subwright-models:/models
      - subwright-config:/config
    deploy:
      resources:
        reservations:
          devices: [{driver: nvidia, count: 1, capabilities: [gpu]}]
volumes:
  subwright-models:
  subwright-config:
```

See [`.env.example`](.env.example) and [`docker-compose.yml`](docker-compose.yml)
for a complete example. The UI is on port 8420.

Requires the
[NVIDIA container toolkit](https://docs.nvidia.com/datacenter/cloud-native/container-toolkit/latest/)
on the host.

### Two commands worth knowing

```bash
docker compose run --rm subwright --self-test    # no GPU needed
docker compose run --rm subwright --check-gpu    # loads the model, reports
```

`--self-test` runs the whole pipeline against a temporary folder with a stub
transcriber and prints a pass/fail table. It validates the image itself, not
just the code, and needs no GPU or model:

```
CHECK  video moved out of ingest/                      PASS
CHECK  subtitles written                               PASS
CHECK  success marker written                          PASS
CHECK  claim removed after success                     PASS
CHECK  long cue capped at 5s                           PASS
CHECK  pre-existing folder without a claim is ignored  PASS
...
RESULT 17/17 PASS
```

## Settings

Everything is configurable from the UI, or by environment variable for the first
run. Environment seeds it; after that the UI is the source of truth.

| Variable | Default | |
|---|---|---|
| `SW_WATCH_DIR` | `/mnt/data/translate` | Folder containing `ingest/` and `reprocess/` |
| `SW_MODEL` | `large-v3` | Whisper model |
| `SW_LANGUAGE` | *(blank)* | Source language, e.g. `ja`. Blank auto-detects. |
| `SW_POLL_INTERVAL` | `30` | Seconds between scans |
| `SW_DEVICE` | `cuda` | `cuda` fails loudly if unavailable; `auto` falls back to CPU |
| `SW_COMPUTE_TYPE` | `int8` | See the note below |
| `SW_SETTLE_SECONDS` | `10` | How long a file must be untouched before it is eligible |
| `SW_KEEP_BACKUPS` | `3` | Old `.srt` files kept when reprocessing |
| `SW_PORT` | `8420` | Web UI port |
| `SW_SHOW_PREVIEW` | `true` | Show the line being transcribed on the dashboard |

**`large-v3-turbo` is deliberately not offered.** It cannot translate, only
transcribe, which would defeat the point.

**There is no target language, and cannot be.** Whisper has exactly two modes:
transcribe (audio to text in the same language) and translate (audio to
*English*). No other target exists in the model. The settings page offers a
source language only.

**Auto-detect is a toggle on the settings page.** Whisper reads roughly the
first 30 seconds to guess. Pin the language when you know it: a file opening on
music, silence or a logo is easy to misread, and a wrong guess does not fail —
it produces fluent, confident, entirely invented subtitles. The job history
shows what was detected and flags anything under 75% confidence.

**On `int8`.** Pascal cards (GTX 10-series, compute 6.1) have no tensor cores and
run float16 at 1/64 of float32 — `float16` there is dramatically *slower*, not
faster. `int8` is the right default for that hardware. On Turing or newer,
`float16` is worth trying.

## Development

```bash
python run.py          # demo mode: no GPU, no model download, instant fake subtitles
pytest -v
```

`run.py` starts it with development defaults and a stub transcriber, so the UI
can be worked on end to end without a GPU. The test suite runs in a couple of
seconds and needs no GPU either — the transcriber sits behind a one-method
interface, so the whole pipeline is tested against a fake.

Test names state behaviours in English, which is deliberate: the list of passing
tests is meant to be readable as documentation.

```
test_video_is_moved_before_transcription_starts             PASSED
test_transcription_failure_leaves_no_partial_srt            PASSED
test_next_startup_resumes_claimed_folder_and_completes_it   PASSED
test_preexisting_library_folder_without_claim_is_untouched  PASSED
```

## Notes on behaviour

**Interrupted jobs are resumed.** If the process is killed mid-transcription the
folder keeps a `.processing` claim, and the job is finished on the next start.

**Only folders it created are ever touched.** Resume adopts a folder *only* if it
holds a `.processing` claim this application wrote. A folder you made yourself,
or one predating this version, is structurally invisible to it — so pointing
subwright at a folder that already contains media will not cause it to
re-transcribe or overwrite anything.

**A file that fails is not retried forever.** A transcription error writes
`.translation_error` and stops there; retrying is a button in the UI. Only an
interrupted *process* resumes automatically.

**Subtitles are written atomically.** A crash cannot leave a truncated `.srt`
that looks complete.

**Progress is position, not an estimate.** The dashboard shows how far into the
audio the job has reached, and the line of subtitle it is producing right now.
There is deliberately no "time remaining": voice detection discards silence, and
how much it will discard is not knowable in advance, so any estimate swings
wildly. A file that ends quietly will finish at around 95% rather than 100% —
the last speech genuinely is not at the end of the file.

The preview shows dialogue on a page that has no authentication. `SW_SHOW_PREVIEW=false`,
or the toggle on the settings page, turns it off while leaving the progress bar.
